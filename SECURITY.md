# Security

## Reporting

Please report suspected vulnerabilities privately to the repository owner through GitHub rather than opening a public issue containing exploit details or sensitive data.

## Public architecture

The GitHub Pages demo is static and performs no live model inference. Browser-only analyst notes remain in local storage. The repository must not contain credentials, API keys, private prompts, licensed article bodies, or private reviewer notes.

## Scope

Security reports may include accidental public-data exposure, cross-site scripting, unsafe export behavior, broken access boundaries, dependency risk, or deployment-integrity failures.

This document does not promise a response time or production security program.
